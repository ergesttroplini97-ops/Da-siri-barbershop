# DA SIRI Barbershop

Sito web premium e responsive realizzato con gli asset ufficiali di DA SIRI Barbershop.

## Avvio in locale

Non richiede installazione o build. Dalla cartella del progetto:

```bash
python3 -m http.server 8080
```

Apri quindi `http://localhost:8080`.

## Pubblicazione

Il progetto è statico e può essere pubblicato direttamente su Vercel, Netlify, Cloudflare Pages o GitHub Pages.

## Dati da completare

Indirizzo, telefono/WhatsApp, orari e listino prezzi non sono stati inseriti perché non ancora confermati.
